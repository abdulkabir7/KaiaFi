# KaiaFi project information

## Submission summary

KaiaFi is an early-stage USDC finance application targeting Arc. The restored interface includes dashboard, lending, borrowing, markets, portfolio, and activity screens. A small Arc USDC deposit/withdraw custody vault is prepared for deployment; it does not lend or pay yield. Borrowing, lending rates, and collateral positions are unavailable.

## Current status

- Frontend framework: React, TypeScript, Vite, and Tailwind CSS.
- Smart contract tooling: Solidity 0.8.20 and Hardhat.
- Arc mainnet: chain ID `5042`; USDC is the native gas currency.
- Deployment: the vault deployment path is prepared, but no KaiaFi vault address, deployment transaction, or public frontend URL has been verified.
- Security: prototype contracts have not been audited and must not be used with real funds.
