# KaiaFi project information

## Submission summary

KaiaFi is an early-stage interface for a planned USDC lending and borrowing application on Arc. The current frontend is a pre-launch shell with Arc mainnet wallet configuration and an explicit empty state. No KaiaFi lending contracts are deployed, and lending, borrowing, market data, and positions are unavailable.

## Current status

- Frontend framework: React, TypeScript, Vite, and Tailwind CSS.
- Smart contract tooling: Solidity 0.8.20 and Hardhat.
- Arc mainnet: chain ID `5042`; USDC is the native gas currency.
- Deployment: no KaiaFi contract deployment or public frontend URL has been verified.
- Security: prototype contracts have not been audited and must not be used with real funds.

This file intentionally omits unverified team roles, performance claims, feature claims, and contact details.
